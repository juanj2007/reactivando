4. DATOS INTERESANTES Y REGLAS DE NEGOCIO CLAVE
===============================================================================

1. MOTOR DE RECOMENDACIONES DE VACANTES PONDERADO:
   El algoritmo inteligente evalúa la compatibilidad Candidato - Vacante mediante:
   - Coincidencia de Ciudad    : 25% del total
   - Nivel de Estudio         : 25% del total
   - Ocupación / Área          : 20% del total
   - Coincidencia Habilidades : 30% del total

2. CONTROL DE POSTULACIONES DUPLICADAS:
   Un candidato NO puede postularse más de una vez a la misma vacante. 
   La regla se valida tanto a nivel de API REST backend como en restricción 
   SQL de unicidad (candidato_id, vacante_id).

3. GEOLOCALIZACIÓN INTERACTIVA DE EMPRESAS:
   Las empresas pueden arrastrar un marcador en Google Maps para guardar 
   sus coordenadas exactas de Latitud y Longitud en la base de datos.

4. TRAZABILIDAD Y AUDITORÍA DE SEGURIDAD:
   Existe una tabla SQL `auditoria` que registra automáticamente la IP del 
   cliente, el usuario, la fecha/hora exacta y la acción ejecutada en operaciones 
   sensibles (logins, publicaciones, cambios de estado).
